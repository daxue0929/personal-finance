## 二、每日安排与 TODO

### 周一 9/14（晚 2.5h）—— 环境搭建 + 第一个程序

- [✓] 安装 Go SDK，配置 GOPATH / GOPROXY（国内代理 `goproxy.cn`）【0.5h】
- [✓] 配置 VSCode Go 插件（gopls、delve 调试器）【0.5h】
- [✓] 跑通 Hello World + `go mod init` 初始化第一个模块【0.5h】
  ```bash
  go mod init # 初始化一个模块，会在当前目录下生成go.mod文件
  go mod tidy # 对于已经有了go.mod的文件夹，可能需要执行的是这个，功能是:这会自动扫描代码里的 import，补全缺失的依赖，修正 // indirect 标记
  go build	#只编译当前目录的包
  go build ./...	 #编译当前模块根目录下所有包（含子目录）
  go build ./cmd/...	#只编译 cmd 子目录下的包
  ```
- [ ] 读 Go 官方文档 [A Tour of Go](https://golang.google.cn/tour/) 前 3 节（基础概【0.5h】
  ```go

  ```
