# 科创50 定投止盈回测 V3 实现计划

## 目标
在 V2(`tasks/backtest_kc50_dca_v2.py` + `科创50_定投止盈_回测报告_V2.md`)基础上,叠加三项优化,生成 V3 脚本、V3 测试、V3 报告。

## 三项优化(已与用户确认)

### 优化3:DCA 再触发推广到所有档位
- V2:DCA 再触发仅 15% 档(`15%≤收益率<20%` 且加仓达上次卖出额一半)。
- V3:推广到任意档 L。当 `not armed[L]` 且 `L ≤ 收益率 < L+5%`(停留在该档上方窄幅震荡区间)且 `自上次止盈累计加仓 ≥ 上次卖出额/2` 时,再卖一次 L(DCA)。
- 沿用 V2 的全局 `last_sell_proceeds` / `dca_since_last_sell`(任一卖出后清零),不引入 per-tier 状态,保持与 V2 一致。
- 因收益率区间 `[L, L+5%)` 任一时刻只命中一个档,每日最多触发一次 DCA。

### 优化6:20% 后回落不跳过 15%(推广到所有档位)
- V2:档 L 在 `收益率 < L−5%` 时重装(15% 跌破10%、20% 跌破15%),导致 20% 后回落到 10%~15% 时 15% 被跳过。
- V3(用户选「推广到所有档位」):档 L 在 `收益率 < L`(跌破自身档位)时重装。即 15% 跌破15%重装、20% 跌破20%重装……跌破任一档即重装该档及更高档,「完整新一轮」,修复所有档位的跳过问题。
- 与 DCA 互补:`[L, L+5%)` 震荡由 DCA(优化3)处理;跌破 L 由重装(优化6)处理,回升到 L 走正常止盈。

### 优化8:卖出比例随档位递增(高位多锁利、低位多留仓)
- V2:每档固定卖 30%。
- V3:`sell_frac(L) = min(0.20 + 0.10*k, 0.90)`,k = (L−0.15)/0.05。
  - 15%→20%、20%→30%、25%→40%、30%→50%、35%→60%、40%→70%……封顶 90%(确保单次至少留 10%,**永不空仓**)。
- 正常止盈与 DCA 再触发均用该档位卖出比例。
- 永不空仓不变式:每次卖 frac<1,留 (1−frac)>0;同日多档连触为各档保留率乘积 >0,叠加每日定投,持仓恒 >0。
