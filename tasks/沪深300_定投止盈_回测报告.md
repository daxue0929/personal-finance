# 沪深300 每日定投 + 阶梯止盈 回测报告

> 数据来源: `personal-finance.index_info` 表, 沪深300指数(index_code=000300)日线收盘价。
> 回测脚本: `tasks/backtest_hs300_dca.py`。

## 一、策略与假设

| 项 | 设定 |
|---|---|
| 标的 | 沪深300指数(000300), 以收盘价模拟可投资净值 |
| 定投 | 每个交易日投入 100.00 元, 自 2010-01-04 起不间断 |
| 止盈档位 | 持仓收益率 ≥10% 卖出当时持仓 30%; ≥15% 卖 60%; ≥20% 卖 90%; >20% 不动 |
| 档位重置 | 持仓收益率跌破 10% 后, 三档重新装填, 下一轮上涨再次依次触发 |
| 持仓收益率 | (持仓市值 − 持仓成本) / 持仓成本, 等价于 (现价 − 平均成本) / 平均成本 |
| 成本结转 | 卖出按比例结转成本(平均成本法), 卖出不改变平均成本 |
| 每日顺序 | 先以当日收盘价定投买入, 再据当日收盘价判定止盈 |
| 费用 | 不计交易费用、分红再投、税收; 指数点位近似可投资(可买碎额) |

## 六、说明

- 本回测以**指数收盘价**模拟净值, 未折算基金跟踪误差、申赎费率与分红, 结果略乐观于真实指数基金定投。
- 持仓收益率为**组合层面**的(市值−成本)/成本; 每日新增定投会抬高平均成本, 因此即便行情横盘, 持仓收益率也会被持续稀释。
- 止盈档位在持仓收益率**自下而上依次穿越**时触发; 跌破 10% 后重新装填, 故 10% 档会在多轮小级别上涨中反复触发, 15%/20% 档仅在强势行情中出现。
- 卖出按比例结转成本(平均成本法), 单次止盈不改变剩余持仓的平均成本。
- 年化收益率为按 244 交易日/年的粗略估算, 仅供参考。
