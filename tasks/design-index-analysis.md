# 前端设计规范 DESIGN.md（指数分析模块）

> 本文件为「指数分析」菜单（指数信息 / 指数分析）的前端设计规范，遵循 CLAUDE.md 强制子流程。新增页面为项目首个数据可视化（ECharts）页面，沿用现有 Element Plus 风格以保持一致。

## 1. 设计原则

沿用项目现有 Element Plus 风格，与持仓看板 / 基金管理 / 基金历史净值页保持一致。指数分析页是首屏数据可视化页面，以"信息密度高但层次清晰"为目标：顶部控制 -> 概览卡片 -> 图表区 -> 定投模拟。

## 4. 字体与间距

- 字体族：`-apple-system, "Helvetica Neue", Helvetica, Arial, sans-serif`（系统默认）
- 标题：16px / font-weight 500；正文：14px；辅助：13px / `#909399`
- 数值：百分比保留 2 位小数；大数值加千分位
- 卡片内 padding：20px；区段间距 16px；卡片间距 16px
- 图表高度：主图 380px，分布图/月度图/定投图 320px

## 5. 布局

### 通用
- 页面外层：`el-card`，`box-shadow:none; border:none`，`margin:20px`
- 搜索/控制区：`padding:20px; border-bottom:1px solid #eee; background:#fafafa`（与 FundManage 一致）

### 指数分析页
1. **顶部控制栏**：指数选择 + 时间快捷按钮组 + 日期范围选择器，右对齐"查询"
2. **概览卡片区**：`el-row` + `el-col`，6~8 个指标卡（最新价/区间涨跌幅/最高/最低/振幅/年化波动率/年化收益率/日均成交额）
3. **主图区**：全宽 `el-card`（收盘价+均线+成交额副图，双 y 轴 + 联动 dataZoom）
4. **双图区**：`el-row` 两列（涨跌幅分布直方图 / 月度收益柱状图）
5. **定投模拟区**：左参数表单（频率/金额/区间复用）+ 右结果卡片，下方累计投入 vs 市值曲线
6. **均线信号**：`el-alert`，根据当前价相对 MA60/MA250 位置给提示

## 6. 组件规范

- `el-select` 选指数：宽度 220px，label = `名称(代码)`
- `el-date-picker` type=daterange，`value-format=YYYY-MM-DD`
- 时间快捷：`el-radio-button` 组（近1月 / 3月 / 6月 / 1年 / 3年 / 全部）
- 指标卡片：`div`，圆角 4px，左边框 3px 强调色，padding 16px，label（13px 灰）+ 数值（24px 加粗，涨跌着色）
- 数值涨跌色：复用现有 `color: v>=0 ? '#f56c6c' : '#67c23a'` 逻辑
- 图表容器：`<div ref="chartRef" :style="{height:'380px'}">`，由 `useEChart` 管理 init/resize/dispose
- 加载：`v-loading` 指令
- 空数据：`el-empty`

## 7. 响应式

- 宽度 >1200px：双图区两列、概览每行 4 个
- 宽度 ≤1200px：双图区单列堆叠、概览每行 2~3 个
- 概览栅格：`xs=12 / sm=8 / md=6`

## 8. 交互

- 切换指数 / 时间快捷 / 改日期范围 -> 重新请求分析数据（概览+图表），定投模拟按当前参数重算
- 定投参数（频率/金额）变化 -> 仅重算定投（独立接口），不重载主图
- 图表 dataZoom 拖动 -> 主图与成交额副图联动
- 均线可勾选显示/隐藏（图例 legend 已支持）
