# 科创50 定投止盈回测 V3(递增卖比 + 50% 清仓封顶 + 全档 DCA 再触发)

> 数据来源: `personal-finance.index_info` 表, 科创50指数(index_code=000688)日线收盘价。
> 回测脚本: `tasks/backtest_kc50_dca_v3.py`。
> 本报告为 V2(`科创50_定投止盈_回测报告_V2.md`)的策略升级版。
> 对比口径: V3/V2/V1/纯定投均用**同一数据区间**(本报告数据日)重跑, 公平对比。

## 一、V3 相对 V2 的策略变更

| 维度 | V2(永不空仓) | V3(递增卖比+50%清仓) |
|---|---|---|
| 止盈档位 | 15% 起, 每涨 5% 一档, 无封顶 | **10% 起, 每涨 5% 一档, 50% 封顶**(共 9 档) |
| 卖出比例 | 每档固定卖当前 30% | **卖比 = 2×档位**(10%卖20%、15%卖30%…50%卖100%), 越涨卖越多 |
| 持仓状态 | **永不空仓**, 每次留 70% 底仓 | 50% 档**清仓封顶**, 其余档留底仓; 触 50% 后持仓归零重建 |
| 重装阈值 | 跌破 L−5% 重装 | **跌破 L−2.5% 重装**(更迟重装, 抗噪声) |
| DCA 再触发 | 仅 15% 档, **全局**追踪累计定投 | **推广到 10%~45% 全部 8 档**, **按档位独立**追踪 |
| DCA 区间 | 仅 [15%,20%) | [10%,15%)…[45%,50%) 共 8 个震荡区间各档独立 |

### 设计逻辑

V2 的「每档固定卖 30%、永不空仓」在强趋势市中保留了过多底仓, 高位锁利不足; 且 DCA 再触发仅限 15% 档, 无法处理更高档位的长期震荡。V3 改为**递增卖比**: 档位越高卖出比例越大(10%卖20%→50%卖100%), 在确保低档轻仓留底、高档重仓锁利的同时, 50% 封顶清仓兑现全部浮盈。重装阈值收紧至 L−2.5%, 减少噪声翻转; DCA 再触发推广到全部 8 个非封顶档位并**按档独立追踪**--每个档位记录自己的「上次减仓以来累计定投」与「上次卖出额」, 互不干扰, 使任意两档间的长期横盘都能定期收割, 提高资金周转。

| 项 | 设定 |

| 卖出比例 | **卖比 = 2×档位**: 10%卖20%、15%卖30%、20%卖40%、25%卖50%、30%卖60%、35%卖70%、40%卖80%、45%卖90%、**50%卖100%(清仓)** |
| DCA 再触发 | 档 L 触发后, 若 L≤收益率<L+5% 且「该档自上次减仓累计定投 ≥ 该档上次卖出额一半」, 再卖一次该档(卖比仍 = 2L); 适用于 10%~45% 共 8 档, 各档独立追踪 |
| 重装规则 | 档位 L 在收益率跌破 **L−2.5%** 时重装(10%:跌破7.5% · 15%:跌破12.5% · … · 50%:跌破47.5%) |
| 50% 清仓 | 50% 档卖 100%, 持仓归零; 之后每日定投重新积累, 收益率跌回近 0 触发全档重装 |
| 持仓收益率 | (持仓市值 − 持仓成本) / 持仓成本 |
| 成本结转 | 卖出按比例结转成本(平均成本法), 卖出不改变平均成本 |
| 每日顺序 | 先以当日收盘价定投买入, 再判定止盈 |
| 回款处理 | 止盈回款留作现金, 不自动再投(再投列为优化方向) |
| 费用 | 不计交易费用、分红再投、税收; 指数点位近似可投资(可买碎额) |

## 七、V3 vs V2 vs V1 vs 纯定投 对比

> 四者均用同一数据区间重跑, 公平对比。V2=永不空仓(每档卖30%); V1=10/15/20% 且 20% 清仓; 纯定投=不止盈持有到期末。

> **核心发现**: V3 总收益率 18.86%, V2 为 24.34%, V3 − V2 = -5.49%(低于 V2); V1 21.83%, 纯定投 99.92%。
> **50% 清仓未触发**: 本回测区间 V3 最高持仓收益率仅 35.42%(V2 为 44.23%), 未达 50% 档, 故 50% 清仓封顶规则在本数据集**未实际生效**, V3 全程未空仓。V3 实际表现为「10% 起步的递增卖比 + 全档 DCA」(无清仓)。50% 清仓逻辑已用合成数据单测验证, 但本行情峰值不足, 未触发。
> V3 弱于 V2 的真实根因(本数据集 V3 全程未清仓, 50% 非因素):
> ①**10% 档过早、过频削薄底仓**: V3 设有 10% 档(卖 20%), 本回测触发 17 次, 在仅 10%~15% 的小涨中就卖出 20% 底仓; V2 从 15% 起卖, 底仓更厚。
> ②**递增卖比在中高位过度减仓**: 20%/25%/30%/35% 档分别卖 40%/50%/60%/70%, 单边大涨时持仓迅速降至个位数百分比--如 2025-08-22 一波 15/20/25/30/35% 五档连触后, 底仓仅剩约 2.5%(0.7×0.6×0.5×0.4×0.3); 而 V2 各档固定卖 30%, 同波段后仍剩 0.7⁴≈24%, 留底仓约为 V3 的 10 倍, 后续科创50 从 1,365 涨到 2,186(+60%) 时 V2 厚底仓吃到远多于 V3 的市值增长。
> ③**锁利总额反更低**: 持仓削薄后单次卖出基数变小, V3 累计实现盈亏 87,976.78 反而**低于** V2 的 113,299.77, 回款 553,711.75 也低于 V2 的 578,481.44--递增卖比在「峰值未超 40%」的行情里, 锁利与留仓两头不讨好。
> **结论**: 在科创50这种「长期上行、峰值未超 50%」的行情里, V2 的「轻仓止盈(每档30%)+永不空仓」优于 V3 的「递增卖比+10%起步」。V3 递增卖比的设计本意是「高位重锁利」, 需行情涨到 40%~50% 才能体现优势, 本数据集未覆盖(最高仅 35.42%)。V3 的真正潜力场景是**大牛市/高波动见顶**行情; 当前数据下, V3 的全档 DCA 再触发(6 次)与更细的 10% 档反而过度交易、抬高机会成本。无论 V3/V2, 止盈总收益仍远低于纯定投(99.92%), 根因依旧是**回款闲置零复利**--最大优化点仍是「回款再投」, 把高位套现的钱在低位重新买入。

## 八、可优化方向

针对科创50 **高波动、强趋势、成长风格** 特性, 在 V3 基础上可考虑:

1. **回款再投(子弹池复利)**: 当前止盈回款闲置, 零复利。可让回款进入子弹池, 在低位(收盘价低于 250 日均线 8% 以上)加速抄底, 把高位套现的钱变成低位筹码。沪深300 V2 已验证此优化可显著提升总收益, 是当前所有止盈版本的最大杠杆。
2. **50% 清仓后回款再投**: V3 的 50% 清仓兑现全部浮盈, 但回款闲置。若清仓回款在随后下跌中分批再投, 可形成「50% 清仓 → 低位回补」的完整大波段高抛低吸, 显著优于清仓后单纯重新定投。需回测验证再投时点。
3. **重装阈值动态化**: 当前「跌破 L−2.5% 重装」为固定百分点。可改为跌破 250 日均线或移动平均成本重装, 更贴合趋势反转; 或给重装加冷却期避免频繁翻转。L−2.5% 比 V2 的 L−5% 更迟重装, 已减少噪声, 但仍可在档位间差异化(低档更敏感、高档更迟钝)。
4. **DCA 再触发半额阈值调整**: 当前「累计定投 ≥ 上次卖出额一半」即再触发。可调高到 60%~80% 减少震荡市过度减仓, 或按档位差异化(低档半额、高档更高比例), 平衡资金周转与底仓保留。
5. **止盈档位动态化**: 当前 10%~50% 固定档。可结合 PE 历史分位、波动率动态调整--高估区提前止盈、低估区放宽阈值。⚠️ index_info 中科创50的 pe_ratio/pe_percentile 当前为 0(未采集), 落地需先补数据。
6. **卖出比例曲线优化**: 当前卖比 = 2×档位(线性)。可改为凸性曲线(低档更轻、高档更重), 或结合波动率--高波动指数(科创50)低档就应多卖以锁定, 低波动则相反。需回测对比。
7. **均线/估值加权定投**: 当前无论涨跌每日固定 300 元, 顶部照样定投抬高成本。可按收盘价相对 250 日均线偏离度加权--低估多投、高估停投, 压低平均成本。科创50波动大于沪深300, 潜力更大。
8. **止盈基准优化**: 当前止盈看「组合整体收益率」, 每日新增定投会持续稀释收益率, 导致横盘时收益率被压低、止盈推迟。可改为按「最早批次成本」或「移动平均成本」分批止盈, 反映不同批次真实盈亏。

## 九、说明与风险

- 本回测以**指数收盘价**模拟净值, 未折算基金跟踪误差、申赎费率与分红, 结果略乐观于真实科创50指数基金定投。
- **50% 清仓**: 50% 档卖出 100%, 持仓归零(含当日定投份额)。清仓后靠每日定投重新积累, 收益率跌回近 0 时全档重装。故 V3 不再是「永不空仓」--触 50% 后存在空仓期。
- **递增卖比**: 同日从低档到高档依次触发时, 每档卖当前持仓的 2L 比例, 累计留存 = ∏(1−2Lᵢ)。如单日涨到 50%, 9 档依次触发后留存 ≈ 0(50% 档清仓); 涨到 45% 则留存 0.8×0.7×0.6×0.5×0.4×0.3×0.2×0.1 ≈ 0.004%, 仍留极少底仓。
- **DCA 再触发** 按档位独立追踪: 每个档位 L 记录自己的「上次减仓以来累计定投」与「上次卖出额」, 当 L 未装填、收益率在 [L, L+5%)、且累计定投 ≥ 该档上次卖出额一半时再卖一次。各档 [L, L+5%) 区间互斥, 同日最多一档 DCA 再触发。DCA 不改 armed 状态, 可连续触发。
- **重装互斥**: 档 L 触发后, 收益率跌破 L−2.5% 才重装。在 [L−2.5%, L) 为等待区(既不 DCA 也不重装)。重装时清空该档 DCA 状态, 待下次 normal 触发重新建立。
- 卖出按比例结转成本(平均成本法), 单次止盈不改变剩余持仓的平均成本。
- 单日涨幅同时穿越多档时, 各档同日依次触发(每档卖当前 2L 比例), 净效果为分档递减减仓; 穿越到 50% 则清仓。
- XIRR 为资金加权年化, 考虑 6 年陆续投入的资金时间价值, 比简单总额法更严谨; 年化(244日/年)为粗略估算。
- 本报告不构成投资建议。
