# 科创50 定投止盈回测 V3(永不空仓 + DCA 全档 + 跌破重装 + 分档卖出)

> 数据来源: `personal-finance.index_info` 表, 科创50指数(index_code=000688)日线收盘价。
> 回测脚本: `tasks/backtest_kc50_dca_v3.py`。
> 本报告为 V2(`科创50_定投止盈_回测报告_V2.md`)的策略升级版。

## 一、V3 相对 V2 的策略变更

| 维度 | V2 | V3 |
|---|---|---|
| DCA 再触发 | 仅 15%~20% 区间 | **推广到所有档**: 任意档 L 在 [L, L+5%) 震荡、加仓达半额即收割 |
| 重装规则 | 跌破 L−5% 重装(15%跌破10%…) | **跌破 L 重装**(15%跌破15%、20%跌破20%…), 完整新一轮, 不跳过 |
| 卖出比例 | 每档固定 30% | **随档位递增**: 15%卖20%、20%卖30%、25%卖40%…封顶90%, 永不空仓 |
| 15% 跳过 | 20% 后回落到 10%~15%, 15% 被跳过 | **不再跳过**: 跌破 15% 同时重装 15% 与 20%, 回升先收割 15% |

### 设计逻辑

V3 在 V2「永不空仓」基础上叠加三项优化, 目标是**提高资金周转与高位锁利**: ① **DCA 再触发全档化**(优化3)--把 V2 仅在 15%~20% 的定期收割推广到任意两档间的长期横盘, 震荡市多周转; ② **跌破自身档位重装**(优化6)--修复 V2「跌破 L−5% 重装」在宽幅震荡中跳过 15% 档的问题, 回撤后完整新一轮、多收割一档; ③ **卖出比例随档位递增**(优化8)--低位档少卖(多留仓吃趋势)、高位档多卖(多锁利), 在永不空仓前提下优化减仓节奏。三项均为对震荡/宽幅行情的增强, 在科创50这类高波动指数上通过回测验证取舍。

## 二、策略与假设

| 项 | 设定 |
|---|---|
| 标的 | 科创50指数(000688), 以收盘价模拟可投资净值 |
| 定投 | 每个交易日投入 300.00 元, 自 2020-02-03 起不间断(无论涨跌) |
| 止盈阶梯 | 持仓收益率 ≥15% 卖当前 `sell_frac(L)`; 此后每涨 5%(20%/25%/30%…)各卖当前 `sell_frac(L)` |
| 卖出比例(优化8) | `sell_frac(L)=min(20%+10%·k, 90%)`, k=(L−15%)/5%; 即 15%卖20%、20%卖30%、25%卖40%……高位多卖、低位多留, **永不空仓** |
| DCA 再触发(优化3) | 任意档 L 触发后, 若 L≤收益率<L+5% 且自上次止盈累计加仓≥上次卖出额一半, 再卖一次 L |
| 重装规则(优化6) | 档位 L 在收益率跌破 L 时重装(15%:跌破15% · 20%:跌破20% · 25%:跌破20%…) |
| 持仓收益率 | (持仓市值 − 持仓成本) / 持仓成本 |
| 成本结转 | 卖出按比例结转成本(平均成本法), 卖出不改变平均成本 |
| 每日顺序 | 先以当日收盘价定投买入, 再判定止盈(重装 → 正常止盈 → DCA 再触发) |
| 回款处理 | 止盈回款留作现金, 不自动再投(再投列为优化方向) |
| 费用 | 不计交易费用、分红再投、税收; 指数点位近似可投资(可买碎额) |

> - **优化6(跌破重装)次之**: +1.21%; 代价是 DCA 再触发被抑制(5->0)、正常止盈 +7 次(小幅回撤即重装再卖), 交易更频繁, 靠「多收割一档」取胜而非 DCA。

## 九、可优化方向

V3 已落地原 V2 优化方向中的 3/6/8。针对科创50 **高波动、强趋势、成长风格** 特性, 仍可考虑:

1. **回款再投(子弹池复利)**: 止盈回款仍闲置, 零复利, 是当前最大优化杠杆。可让回款进入子弹池, 在低位(收盘价低于 250 日均线 8% 以上)加速抄底, 把高位套现的钱变成低位筹码。沪深300 V2 已验证此优化可显著提升总收益。
2. **均线/估值加权定投**: 无论涨跌每日固定 300 元, 顶部照样定投抬高成本。可按收盘价相对 250 日均线偏离度加权--低估多投、高估停投, 压低平均成本。
3. **止盈档位动态化**: 15/20/25% 为固定档。可结合 PE 历史分位、波动率动态调整--高估区提前止盈、低估区放宽阈值。⚠️ index_info 中科创50的 pe_ratio/pe_percentile 当前为 0(未采集), 落地需先补数据。
4. **重装冷却/迟滞**: 优化6 推广到全档后, 小幅回撤即重装可能造成 15% 档高频触发。可给重装加冷却期(如重装后 N 个交易日不再重装)或迟滞带(跌破 L−1% 才重装), 减少噪声触发的过早减仓。
5. **止盈基准优化**: 止盈看「组合整体收益率」, 每日新增定投会持续稀释收益率, 导致横盘时收益率被压低、止盈推迟。可改为按「最早批次成本」或「移动平均成本」分批止盈, 反映不同批次真实盈亏; 并使高档 DCA(优化3)更易满足半额条件。
6. **卖出比例曲线调参**: 优化8 当前为线性 20%+10%·k、封顶 90%。可回测不同曲线(凹型/凸型/不同封顶)对总收益率的影响, 寻找科创50历史数据上的较优减仓节奏。

## 十、说明与风险

- 本回测以**指数收盘价**模拟净值, 未折算基金跟踪误差、申赎费率与分红, 结果略乐观于真实科创50指数基金定投。
- **永不空仓**: 每次卖 `sell_frac(L)` < 1(封顶 90%, 至少留 10%), 即便连触多档, 各档保留率乘积 > 0, 加之每日定投持续加仓, 持仓始终 > 0。
- **优化3(DCA 全档)**: 任意档 L 在 [L, L+5%) 震荡、累计加仓达上次卖出额一半时再卖一次 L; 沿用 V2 的全局「自上次止盈累计加仓 / 上次卖出额」口径(任一卖出后清零), 非 per-tier 状态。因定投稀释拉低收益率, 高档(L≥20%)需收益率长期滞留窄区间才触发, 实际频率见各档 DCA 次数。
- **优化6(跌破重装)**: 档 L 在收益率跌破 L(自身档位)时重装, 跌破任一档即重装该档及更高档, 「完整新一轮」; 故 20% 后回落到 10%~15% 会同时重装 15% 与 20%, 回升时先收割 15%, 不再跳过。副作用: 小幅回撤即重装, 震荡市 15% 档触发更频繁(见消融表)。
- **优化8(分档卖出)**: 15%卖20%、20%卖30%、25%卖40%……高位多卖、低位多留; 封顶 90% 保证永不空仓。正常止盈与 DCA 再触发均用本档比例。注: 比例卖出虽不改变当时平均成本, 但缩小持仓基数, 使后续每日定投更快抬高平均成本, 故 V3 区间最高持仓收益率(34.85%)低于 V2(44.23%); 这也是高位多锁利的代价之一。
- 单日涨幅同时穿越多档时, 各档同日依次触发(每档卖当前 `sell_frac(L)`), 净效果为分档减仓而非清仓。
- 卖出按比例结转成本(平均成本法), 单次止盈不改变剩余持仓的平均成本。
- XIRR 为资金加权年化, 考虑 6 年陆续投入的资金时间价值, 比简单总额法更严谨; 年化(244日/年)为粗略估算。
- 本报告不构成投资建议。
